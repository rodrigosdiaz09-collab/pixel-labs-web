# Nuevas fotos en Deco

Se agregaron siete fotos al inicio de Deco: colección de arcoíris, Wanda, Aura, Juana, cuadro de Malvinas, arquero con LED y futbolista con LED.

Cada ficha incluye descripción, vista ampliada, enlace para compartir, selección y consulta por WhatsApp. Se conservan las fotografías completas en JPG y se usan miniaturas WebP para la grilla. No se asignaron precios nuevos: los trabajos se consultan a medida. El probador conserva los diseños que ya tenían recortes preparados.

El catálogo ahora tiene 89 fichas, de las cuales 38 son de Deco. Se conserva la paleta del nuevo logo, los precios existentes y la animación de la máquina.

Para publicar: copiá el contenido de `pixel-labs-web` sobre tu proyecto en VS Code y enviá los cambios a GitHub para que Cloudflare los publique. Esta entrega actualiza el ZIP; no modifica por sí sola la web activa.

Verificación: archivos, miniaturas, enlaces de consulta, metadatos y cantidades comprobados. La sintaxis JavaScript es válida. No se pudo repetir la vista en navegador porque el navegador local no inició en esta sesión.
